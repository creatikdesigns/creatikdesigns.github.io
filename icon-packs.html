Getting Started

How to apply icon packs

Quick guide to get your new icons running in minutes.

1

Install a Supported Launcher

Nova Launcher, Action Launcher, Lawnchair, Niagara, or any launcher with icon pack support

2

Download the Icon Pack

Install your chosen icon pack from the Google Play Store

3

Apply in Launcher Settings

Open launcher settings → Icon Pack → Select your pack → Apply
